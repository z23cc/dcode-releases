# DCode

Installers for DCode, a local desktop app for running coding agents on your own machine. This repository holds releases only; the source lives elsewhere.

## Install (macOS, Apple silicon)

1. Download [`dcode-desktop-macos-arm64.dmg`](https://github.com/z23cc/dcode-releases/releases/latest/download/dcode-desktop-macos-arm64.dmg) from the latest [release](https://github.com/z23cc/dcode-releases/releases/latest).
2. Open it and drag **DCode** into **Applications**.
3. Launch DCode. If macOS says it cannot verify the developer, open **System Settings → Privacy & Security** and click **Open Anyway**.

DCode updates itself from this repository once it is installed.

## Problems

Open an [issue](https://github.com/z23cc/dcode-releases/issues) with what you did and what you saw. **Help → Report Issue** in the app can attach a diagnostic bundle.
